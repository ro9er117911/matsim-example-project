# 災難撤離行為模型研究：社會影響與恐慌傳播探討

在極端災難撤離模擬中，人與人之間的資訊傳遞與心理狀態對整體路網效能有顯著影響。本文件分析 MATSim 框架下可整合的行為模型。

---

## 1. 社會影響模型 (Social Influence Model)

### 1.1 機制概述
代理人不再是獨立決策者，其撤離意願會受到鄰近代理人（或社交網絡中的聯絡人）的行為影響。
- **門檻模型 (Threshold Model)**：當周邊 50% 的代理人開始撤離時，該代理人才會觸發撤離計畫。
- **資訊衰減**：撤離資訊的價值隨距離與時間增加而減少。

### 1.2 在 MATSim 中的適用性
- **優點**：能解釋「群聚效應」與撤離初期的遲滯現象。
- **挑戰**：需要定義複雜的人口社交屬性標籤 (`Social Network Graph`)，計算開銷大。

---

## 2. 恐慌傳播模型 (Panic Propagation)

### 2.1 機制概述
恐慌被視為一種透過空間接觸傳染的「病毒」。
- **參數**：傳染率 (Infection Rate)、冷卻率 (Cooling Rate)。
- **行為改變**：處於恐慌狀態的代理人會隨機改變路徑 (Random Routing) 或採取極端侵略性的駕駛行為（縮短安全距離）。

### 2.2 在 MATSim 中的適用性
- **優點**：能模擬出災難現場的次生災害或局部踩踏風險。
- **挑戰**：MATSim 的 QSim 是基於 Queue Logic，較難表現微觀層級的「物理碰撞」與「侵略性駕駛」，通常需要在 `MobsimListener` 中動態修正 Link 參數 (Capacity/Freespeed)。

---

## 3. 預備研究建議：哪種模型最適合後續分析？

綜合現有研究與本專案的「大規模場景 (5000+ Agents)」需求，我建議優先考慮：

### **推薦方案：演化決策模型 (Evolutionary Decision Model)**
並非直接模擬恐慌，而是在 Scorer 層級加入「環境威脅負效用」：
1.  **動態效用權重**：隨著災難（如水位上升）逼近，`traveling` 的負效用係數 $\beta$ 會動態降低（追求速度超過追求安全）。
2.  **時變路權限制**：結合 `Time-variant Network`，強制將被淹沒區域的通行能力降為零。

### **評選理由**
- **相容性**：與 MATSim 原生的計畫評分邏輯完全相容。
- **效率**：不需要即時計算複雜的社交矩陣。
- **解釋力**：能有效展現出「撤離時間視窗」縮減時的群體擁塞行為。
