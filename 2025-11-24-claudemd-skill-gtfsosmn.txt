  ⎿  5000_disatar Network Build Plan

     Overview

     Build MATSim PT network from GTFS (bus + metro) and OSM data in phases:
     - Phase 1: Test subset (metro + 100 bus routes)
     - Phase 2: Full scale (all 5,345 bus routes)
     - Strategy: Real network mapping → Artificial fallback if stuck

     Deliverables

     1. network-with-pt.xml - Multimodal network with PT routes mapped
     2. transitSchedule-mapped.xml.gz - PT schedules mapped to network
     3. transitVehicles.xml - PT vehicle definitions

     ---
     Phase 1: Test Subset Setup

     1.1 Build Maven Project

     ./mvnw clean package

     1.2 Create Test GTFS Subsets

     - Metro: Use full metro GTFS (722 stops, 7 routes)
     - Bus: Filter to 100 routes covering metro catchment areas
     - Create 5000_disatar/GTFS_TEST/ directory with subsets

     1.3 Convert OSM → Network

     java -cp pt2matsim/work/pt2matsim-25.8-shaded.jar \
       org.matsim.pt2matsim.run.Osm2MultimodalNetwork \
       5000_disatar/OSM/disaster_bbox.osm.pbf \
       5000_disatar/output_test/network.xml \
       5000_disatar/output_test/osm_config.xml
     Expected: Network with car, walk, rail modes

     1.4 Convert GTFS Coordinates (WGS84 → EPSG:3826)

     # Bus test subset
     ./mvnw exec:java 
     -Dexec.mainClass="org.matsim.project.tools.ConvertGtfsCoordinates" \
       -Dexec.args="--input 5000_disatar/GTFS_TEST/bus_test/ \
                    --output 5000_disatar/GTFS_TEST/bus_test_converted.zip \
                    --targetCRS EPSG:3826"

     # Metro (full)
     ./mvnw exec:java 
     -Dexec.mainClass="org.matsim.project.tools.ConvertGtfsCoordinates" \
       -Dexec.args="--input 5000_disatar/GTFS/metro_disaster_gtfs/ \
                    --output 5000_disatar/GTFS_TEST/metro_converted.zip \
                    --targetCRS EPSG:3826"

     1.5 Convert GTFS → MATSim

     # Bus
     ./mvnw exec:java 
     -Dexec.mainClass="org.matsim.project.tools.GtfsToMatsim" \
       -Dexec.args="--gtfsZip 5000_disatar/GTFS_TEST/bus_test_converted.zip 
     \
                    --network 5000_disatar/output_test/network.xml \
                    --outDir 5000_disatar/output_test/bus \
                    --targetCRS EPSG:3826"

     # Metro
     ./mvnw exec:java 
     -Dexec.mainClass="org.matsim.project.tools.GtfsToMatsim" \
       -Dexec.args="--gtfsZip 5000_disatar/GTFS_TEST/metro_converted.zip \
                    --network 5000_disatar/output_test/network.xml \
                    --outDir 5000_disatar/output_test/metro \
                    --targetCRS EPSG:3826"

     1.6 Merge Transit Schedules

     ./mvnw exec:java 
     -Dexec.mainClass="org.matsim.project.tools.MergeGtfsSchedules" \
       -Dexec.args="--schedule1 
     5000_disatar/output_test/bus/transitSchedule.xml \
                    --schedule2 
     5000_disatar/output_test/metro/transitSchedule.xml \
                    --vehicles1 
     5000_disatar/output_test/bus/transitVehicles.xml \
                    --vehicles2 
     5000_disatar/output_test/metro/transitVehicles.xml \
                    --output 5000_disatar/output_test/merged/"

     1.7 Prepare Network for PT Mapping

     ./mvnw exec:java 
     -Dexec.mainClass="org.matsim.project.tools.PrepareNetworkForPTMapping" 
     \
       -Dexec.args="5000_disatar/output_test/network.xml \
                    5000_disatar/output_test/network-cleaned.xml"

     1.8 PT Mapping - Real Network Mode (Try First)

     # Create config
     java -cp pt2matsim/work/pt2matsim-25.8-shaded.jar \
       org.matsim.pt2matsim.run.CreateDefaultPTMapperConfig \
       5000_disatar/output_test/ptmapper-config-real.xml

     # Edit config: maxLinkCandidateDistance=300, maxTravelCostFactor=15.0
     # Run mapping (set 10-min timeout)
     timeout 600 java -Xmx10g -cp pt2matsim/work/pt2matsim-25.8-shaded.jar \
       org.matsim.pt2matsim.run.PublicTransitMapper \
       5000_disatar/output_test/ptmapper-config-real.xml
     Success criteria: Completes in <10 min, <30% artificial links

     1.9 PT Mapping - Artificial Mode (Fallback)

     If real mode fails or >30% artificial links:
     # Edit config: maxLinkCandidateDistance=0.0
     timeout 120 java -Xmx10g -cp pt2matsim/work/pt2matsim-25.8-shaded.jar \
       org.matsim.pt2matsim.run.PublicTransitMapper \
       5000_disatar/output_test/ptmapper-config-artificial.xml

     1.10 Validate Test Outputs

     # Check plausibility
     java -cp pt2matsim/work/pt2matsim-25.8-shaded.jar \
       org.matsim.pt2matsim.run.CheckMappedSchedulePlausibility \
       5000_disatar/output_test/network-with-pt.xml.gz \
       5000_disatar/output_test/transitSchedule-mapped.xml.gz

     # Count stops, routes, vehicles
     rg '<stopFacility' 
     5000_disatar/output_test/transitSchedule-mapped.xml.gz | wc -l
     rg '<transitLine' 
     5000_disatar/output_test/transitSchedule-mapped.xml.gz | wc -l

     ---
     Phase 2: Full Scale Network

     2.1 Convert Full GTFS

     Repeat steps 1.4-1.6 with full bus GTFS (5,345 routes, 71,047 stops)
     Output to 5000_disatar/output_full/

     2.2 PT Mapping - Full Scale

     Use same strategy (real → artificial fallback)
     Expect longer processing time (20-30 min for real mode)

     2.3 Final Deliverables

     Copy final files to project root:
     cp 5000_disatar/output_full/network-with-pt.xml.gz \
        5000_disatar/network-with-pt.xml

     cp 5000_disatar/output_full/transitSchedule-mapped.xml.gz \
        5000_disatar/transitSchedule-mapped.xml.gz

     cp 5000_disatar/output_full/transitVehicles.xml \
        5000_disatar/transitVehicles.xml

     ---
     Key Decisions Checkpoint

     - Phase 1 success? → Proceed to Phase 2
     - Real mapping stuck? → Switch to artificial mode
     - Artificial links >30%? → Acceptable for disaster scenario
     - Test validates? → Scale to full dataset
