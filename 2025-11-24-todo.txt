⏺ 10 Agent 測試模擬問題分析

  遇到的問題與解決方案

  1. Population XML 格式錯誤

  錯誤：Element <population> has no attribute "name"
  原因：population_v6.dtd 不支持 name 屬性
  解決：移除 <population name="test_population_10agents"> 中的 name 屬性

  2. SwissRailRaptor 配置參數錯誤

  錯誤：Parameter transferPenaltyMaximum is not part of the valid parameters
  原因：參數名稱錯誤
  解決：
  - transferPenaltyMaximum → transferPenaltyMaxCost
  - transferPenaltyMinimum → transferPenaltyMinCost

  3. PT 車輛類型缺失

  錯誤：Could not find requested vehicle type = pt
  原因：vehiclesSource="modeVehicleTypesFromVehiclesData"
  要求為所有模式定義車輛類型，但 transitVehicles.xml 只有 bus_Bus 和
  metro_Subway
  解決：改為 vehiclesSource="defaultVehicle" 使用預設車輛

  4. QSim 模組配置錯誤

  錯誤：Parameter useTransit is not part of the valid parameters
  原因：useTransit 不屬於 qsim 模組（屬於 transit 模組）
  解決：從 qsim 模組移除 useTransit 參數

  5. 多 Leg 行程結構問題

  錯誤：Found a trip with multiple legs and no routingMode. Person id 
  mixed_agent_02
  原因：mixed_agent_02 有 walk→pt_interaction→pt 的複雜結構但缺少
  routingMode 屬性
  解決：簡化為單一 PT 行程
